# 사진 기록 캘린더 프론트

React · TypeScript · Vite. 구현 기준은 상위 `design.md`와 `../img/1.png`입니다.

## 로컬 실행

```bash
cd frontend
npm ci
npm run dev
```

브라우저에서 터미널에 표시된 로컬 주소를 엽니다. Spring Boot를 별도로 `127.0.0.1:8080`에서 실행해야 실제 로그인이 가능합니다. 계정 설정은 상위 `AUTH.md`를 참고하세요. 로컬 HTTP에서는 `SESSION_COOKIE_SECURE=false`를 사용합니다.

다른 로컬 백엔드 주소는 `.env.example`을 `.env.local`로 복사하고 `API_PROXY_TARGET`을 변경합니다. 운영 HTTPS 서버를 로컬 HTTP 개발 프록시에 연결하면 Secure 쿠키가 맞지 않을 수 있으므로 로컬 백엔드를 사용하세요. 비밀번호는 로그인 입력란에서만 입력하며 저장하지 않습니다.

```bash
npm test
npm run build
npm run test:browser
```

## 이번 단계

- 세션 확인, CSRF 기반 로그인, 로그인 오류·요청 제한·세션 만료 처리.
- 메인 화면, 현재 한국시간 월의 카테고리별 미니 캘린더·기록 수, API 연결.
- 빈 목록, 로딩, 전체 조회 실패와 개별 카드 재시도.
- 카테고리 캘린더: 최근 2개 연도 월간 세로 탐색, 보이는 월부터 API 조회, 월 제목/월 선택으로 이동, 오늘 복귀, 하단 카테고리 전환.
- 사진이 있는 기록은 서명 URL로 조회하고 기록 시간을 중앙에 표시. 사진 없는 기록과 사진 조회 실패는 카테고리 색상으로 표시.
- 연간 보기: 최근 2개 연도, 12개월 × 31일 Heatmap, 없는 날짜는 빈칸, 미래는 회색. 내부 스크롤, Escape/닫기/바깥 클릭 지원.
- 기록 작성/수정: 선택 날짜 고정, 기록 시간·메모 필수, 사진 1장 선택/변경/제거. CSRF 기반 생성·수정 API 연결.
- 사진은 JPEG/PNG, 20MB 이하만 선택 가능하며 서버가 2천만 화소 제한과 실제 파일 형식을 검증합니다. 업로드 API 사용에는 백엔드 사진 저장소 설정이 필요합니다(`../PHOTO_STORAGE.md`).
- 저장 실패 시 입력을 유지하며 이미 업로드한 사진 키를 재사용해 재업로드를 피합니다. 사진을 변경하지 않은 수정은 기존 사진을 유지합니다.
- 상세 기록: 시간·사진·메모, 수정 메뉴, 삭제 확인/취소 및 CSRF 기반 삭제. 사진 없는 기록은 이미지 영역을 생략합니다.
- 통합 캘린더: 최근 2개 연도 월간 세로 탐색, 월 선택·오늘 복귀. 서버의 `completedCount/totalCount`를 그대로 표시해 과거 분모를 유지합니다.
- 일간 모아보기: 해당 날짜 당시 활성 카테고리를 표시 순서대로 같은 크기의 3열 카드에 나열합니다. 기록 없는 카테고리는 빈 카드에서 날짜를 유지한 기록 작성으로 연결합니다. 삭제된 카테고리는 과거 날짜에서도 표시하지 않습니다. 기록 있는 카드는 사진/시간 또는 색상 대체 셀과 상세 화면으로 연결하고 마지막 행은 왼쪽 정렬합니다.
- 일간 피드: 기록 시간 오름차순, 카테고리명·시간·메모, 사진 없는 기록은 사진 영역 생략. 사진 안에 시간 텍스트를 넣지 않습니다.
- 모아보기/피드에서 진입한 상세 기록은 해당 화면으로 돌아갑니다. 기록 수정 후에도 돌아갈 경로를 유지합니다.
- 카테고리 관리: 목록·색상·비공개 표시, 핸들을 통한 터치/마우스 드래그와 키보드/위아래 버튼 순서 변경. 활성 카테고리 전체 ID를 보내며 저장 실패 시 이전 순서로 되돌립니다.
- 카테고리 추가/수정: 이름(최대 50자)·색상·비공개 설정. 저장 실패 시 입력 유지, 삭제 전 연결 기록·사진 삭제 및 복구 불가 안내와 취소/삭제 확인 제공.
- 비공개를 꺼도 자동 공개되지 않으며 공유 기능은 아직 제공하지 않습니다.
- Pretendard를 로컬 폰트로 제공하며 iPhone 17e 기준 390×844 세로/가로 레이아웃과 안전 영역을 지원.

개발/테스트용 가짜 데이터는 제품에 넣지 않습니다. 접근성: 링크·버튼의 의미, 폼 레이블, 키보드 포커스, 오류 안내, 동작 감소 설정 지원.

## 운영 연결 기준

빌드 결과는 `dist/`입니다. 운영에서는 정적 파일과 `/api`를 같은 HTTPS origin에서 제공해야 합니다. 운영 Nginx는 아직 API 전용입니다. 정적 화면과 API를 함께 제공하는 설정 및 배포 묶음을 준비했으며, 절차는 `../deploy/lightsail/FRONTEND_RELEASE.md`에 정리했습니다. API 인증·CSRF·쿠키·CORS 정책은 변경하지 않았습니다. 이번 작업에서 운영 서버에는 배포하지 않았습니다.

캘린더 월·오늘 판단은 `Asia/Seoul` 기준이며, 포커스 복귀 또는 30초 주기로 날짜를 갱신합니다. 기록 비율의 분모는 해당 월 전체 날짜 수입니다.
